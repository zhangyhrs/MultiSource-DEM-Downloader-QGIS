# Changelog

## 1.0.0

- Initial public release of **Multi-Source DEM Downloader**.
- Added Copernicus DEM GLO-30 and GLO-90 public-cloud download.
- Added SRTM and NASADEM discovery/download through NASA Earthdata.
- Added JAXA AW3D30 registered-user access with retry, proxy and network-stability handling.
- Added AOI selection from current map extent, interactive drawing, active polygon layer and external vector files.
- Added mosaicking, study-area clipping, automatic loading into QGIS and optional hillshade generation.
- Added compact collapsible QGIS-style dock interface.
